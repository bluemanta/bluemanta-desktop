# 工作台设计简报 v0.1

- 日期：2026-10-11
- 状态：草案，待用户确认
- 依据：[ADR 0005](../decisions/0005-web-app-dsh-entry.md)（核心功能做成独立网页，dsh 只做入口）

## 1. 为什么现在做

工作台以后主要在浏览器里用，会逐步装下灵感台、内容生产、项目管理、知识库、家庭等模块。视觉和交互规范要在写网页代码之前定下来，否则各模块各做各的，统一的代价会越来越大。

本设计阶段与阶段 1 试用并行。产出的规范作为阶段 1.5「灵感台迁网页」的必读材料，并决定网页用什么组件库。

## 2. 用户已确定的方向（2026-10-11）

| 问题 | 决定 |
|---|---|
| 与 SalesOS Console 的关系 | **同一家族**：共享骨架（间距体系、排版层级、组件行为、无障碍底线）。但工作台要从一开始就把间距和组件做规范；SalesOS 因为历史原因在这方面不够统一，不照搬它的现状 |
| 嵌在 dsh 里的外观 | **自己的风格，只有深浅色跟随 dsh**。独立打开和嵌入时外观一致 |
| 风格取向 | **工具感，信息密度高**。间距和菜单尽量紧凑，不要大片留白，把页面空间用起来 |
| 参考产品 | Linear、Things 3 / Craft、Arc / Raycast |
| 原型方式 | Claude Code 做 HTML 可点原型（虚构数据），用户在浏览器里看，逐轮修改 |

### 从参考产品里取什么

| 参考 | 取 | 不取 |
|---|---|---|
| Linear | 克制的中性色加一个主色；紧凑的列表行；键盘优先，命令面板（⌘K）；细线分隔代替卡片 | 过冷的纯灰，以及默认隐藏信息 |
| Things 3 / Craft | 细节精致：圆角、阴影、字重的分寸；温暖的底色；完成和收藏这类小动作的手感 | 大留白、低信息密度 |
| Arc / Raycast | 流畅感：快速切换、恰到好处的过渡动效；侧栏的轻盈质感；有个性的强调色 | 大面积渐变、毛玻璃堆叠、会干扰阅读的动效 |

## 3. 密度基线（相对 SalesOS 收紧一档）

| 项 | SalesOS Console | 工作台（起点，原型中再调） |
|---|---|---|
| 正文 / 列表 | 14px / 1.6 | 13px / 1.5 |
| 辅助信息 | 13px | 12px |
| 页面标题 | 22–24px | 18px |
| 列表行高 | ≥48px | 32–36px（单行），两行内容 ≤52px |
| 紧凑控件 | 36px | 28px（鼠标）；触控设备 36px |
| 面板内边距 | 16px | 12px |
| 模块间距 | 16–24px | 12–16px |
| 侧栏 | 192 / 56px | 208 / 48px |
| 间距体系 | 4 的倍数 | 同（4、8、12、16、20、24…），新增 2 和 6 只用于图标与文字的微调 |

无障碍底线不因紧凑而放松：
- 文字对比度 4.5:1；
- 指针目标不小于 24×24px（WCAG 2.2 AA）；
- 焦点始终可见；
- 不用 10–11px 的字承载信息。

## 4. 信息架构（草案）

### 模块

| 模块 | 状态 | 说明 |
|---|---|---|
| 灵感台 | 已有（阶段 1），迁网页 | 清单、统计、回收站 |
| 项目 | core 已有对象，界面待做 | 成长、项目档案（T4 已导入）、任务 |
| 内容 | 暂缓 | 账号、选题、产出、发布台；先用 Notion 摸索 |
| 知识库 | 阶段 3 | 卡片、检索 |
| 家庭 | 未定 | — |

### 布局骨架

```
┌────────┬──────────────────────────────┬──────────────┐
│ 一级导航 │ 页头：模块名 · 二级切换 · 搜索 · 新增 │              │
│（模块）  ├──────────────────────────────┤  详情（可选） │
│         │ 列表 / 主内容                   │  可多 tab     │
│         │                               │              │
└────────┴──────────────────────────────┴──────────────┘
```

- **一级导航**放模块；**二级切换**放在页头里，用分段控件或下拉，不再单独占一列。这一点与现在的 dsh 插件版灵感台不同（那里二级菜单单独占一列），目的是省出横向空间。
- **列表与详情左右分栏**，沿用 `idea-ui.md` 第 9 节已确认的交互（分栏宽度可拖、详情多 tab、窄屏整页）。
- **命令面板（⌘K）**：跨模块搜索、跳转、新建。所有常用动作都有键盘快捷键。

### 嵌在 dsh 里时

dsh 自己有左侧栏，网页再放一列一级导航会出现两列侧栏。规则：

- dsh 左侧栏为每个模块各放一个入口（灵感台、项目……），点开后主区嵌入网页并直接定位到该模块；
- **嵌入模式下网页隐藏自己的一级导航**，模块切换交给 dsh 左侧栏；
- 网页的页头、列表、详情在两种模式下完全一致；
- 深浅色跟随 dsh（S3 消息桥的 `bm:theme`，只取深浅色，不取 dsh 的配色）。
