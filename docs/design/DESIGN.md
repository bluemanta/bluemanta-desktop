# bluemanta 工作台视觉与交互规范 v1.0

状态：2026-10-11 用户认可第 2 轮可点击原型（[prototypes/workbench-v1](prototypes/workbench-v1/index.html)），定为 v1.0。原型认可不等于正式页面验收；正式页面实现后，按第 10 节逐项验收，并首次经用户认可后才登记截图基线。

适用于工作台网页（灵感台，以及之后的项目、任务、内容、知识库等模块），包括独立打开和嵌在 dsh 里两种方式（[ADR 0005](../decisions/0005-web-app-dsh-entry.md)）。不适用于 dsh 插件自身的入口和工具卡片：那些跟随 dsh 的主题变量。

## 1. 文件与优先级

| 文件 | 作用 |
|---|---|
| [tokens.css](tokens.css) | 视觉数值的唯一编辑入口：颜色、字号、间距、尺寸、圆角、阴影、动效。网页工程直接引入 |
| 本文件 | 规则：什么时候用哪个变量、页面怎么排、交互怎么做、怎么验收 |
| [reference.html](reference.html) | 读取 tokens.css 的组件样例页，虚构数据。实现组件时对照 |
| [brief.md](brief.md) | 设计简报：方向、信息架构、参考取舍 |
| [prototypes/workbench-v1](prototypes/workbench-v1/index.html) | 已认可的交互原型。规范没写到的细节，以原型为准 |

规则分两级：**必须**用于无障碍、数据真实性和一致性底线；**默认**是可调整的设计选择。需要偏离默认时，在 PR 描述里写明原因和影响的组件即可，不必另行审批。用户当前的指令优先。

和 SalesOS Console 的关系：同一家族，共用间距体系、排版层级、组件行为和无障碍底线；配色和密度是工作台自己的，不照搬 Console 现状。

## 2. 设计原则

1. **工具感，高密度。** 把页面空间用在内容上，不留大片空白。列表单行 34px，页头 46px，筛选条 32px。
2. **层次靠底色和浮起，不靠线。** 暖白底（canvas）上，选中的行和详情是白色（surface）浮起的卡片。列表行之间不画分隔线。
3. **一个主色，克制使用。** 绿色只用于：当前选择、主操作、分组标题、链接、焦点。不把绿色当作「成功」。
4. **键盘优先，鼠标同样顺手。** 常用操作都有快捷键，并在按钮或命令面板里显示。
5. **可撤销优于确认。** 可逆的操作（移入回收站、取消收藏）直接执行，并给出撤销；不可逆的操作（彻底删除、丢弃未保存修改）才弹确认。
6. **状态说真话。** 读取失败、显示缓存、结果未确认，都要持续可见地说明，不能折叠掉，也不能伪装成成功。

## 3. 色彩

数值见 tokens.css，这里只写用法。

| 变量 | 用途 | 不要用于 |
|---|---|---|
| `--bm-canvas` | 页面底、页头、筛选条、分组标题吸顶的底色 | 卡片 |
| `--bm-surface` | 详情面板、卡片、选中行、输入框、弹窗 | 整页底 |
| `--bm-side-bg` | 侧栏 | 其他区域 |
| `--bm-hover` | 悬停底色、分段控件的槽 | 选中态 |
| `--bm-sel` | 命令面板里的选中项 | 列表选中（列表选中用 surface 加 shadow-row） |
| `--bm-text` / `-2` / `-3` | 主要文字 / 说明与次要文字 / 时间、计数、元信息 | 用透明度调出浅色字 |
| `--bm-line` | 装饰分隔（卡片边、详情区块之间） | 控件唯一的边界 |
| `--bm-line-strong` | 按钮描边、原文引用线、分段之间的竖线 | — |
| `--bm-accent` 系列 | 见原则 3 | 成功状态、大面积色块 |
| `--bm-star` | 收藏星标 | 警告 |
| `--bm-mark` | 搜索命中高亮 | 其他强调 |
| `--bm-danger` / `--bm-warn` 及对应 `-soft` | 错误与危险操作 / 待确认、降级、缓存提示。危险色填充的按钮用 `--bm-on-danger` 作文字色（深色模式下是深色字） | 装饰 |
| `--bm-cat-*` | 分类色点（7px 圆点） | 文字颜色、大面积底色 |

**必须：**
- 文字对比度不低于 4.5:1。tokens.css 中所有文字色在全部底色上已核对（2026-10-11），新增颜色要重新计算；
- 区分控件和状态所必需的非文字元素（焦点框、选中标识、输入框边界）不低于 3:1；
- 颜色不能是唯一的信息：分类有文字，星标有 `aria-pressed` 和可访问名称，未保存除了绿点还有确认。

## 4. 字体、间距与形状

| 用途 | 字号 / 行高 / 字重 |
|---|---|
| 页头模块名 | 14px / 1.5 / 600 |
| 详情标题 | 18px / 1.35 / 600 |
| 正文、列表、控件 | 13px / 1.5 / 400；列表标题 500 |
| 详情正文 | 14px / 1.65 / 400 |
| 时间、元信息、筛选、标签 | 12px / 1.5 / 400–500 |
| 键盘提示、徽标数字 | 11px（等宽）；不承载信息性正文 |
| 指标数值 | 22px / 1.3 / 600，等宽数字 |

- 中文不用负字距；英文标题可用 -0.01em。数字列一律 `font-variant-numeric: tabular-nums`。
- 间距用 4 的倍数；2 和 6 只用于图标与文字之间的微调。
- 面板内边距 12–16px；同组元素 4–8px；区块之间 12–16px；页面左右边距 16px（列表区内嵌 8px）。
- 圆角：控件和列表行 7px；卡片和详情 10px；弹窗和命令面板 14px；胶囊（11px）只用于筛选和来源徽标。
- 阴影：列表选中行用 `shadow-row`；卡片和详情用 `shadow-card`；浮层用 `shadow-pop`。普通区域不加阴影。
- 不用渐变、毛玻璃和装饰性动效。

## 5. 布局与响应式

```
┌─────────┬──────────────────────────────────┬──────────────────┐
│ 侧栏 208  │ 页头 46：模块名 · 分段切换 · 搜索 · 主操作 │                  │
│ 模块导航   ├──────────────────────────────────┤  详情卡片 420      │
│ ⌘K 入口   │ 筛选条 32                         │  可拖 320–720     │
│           │ 列表（按日期分组，组标题吸顶）      │  多标签           │
└─────────┴──────────────────────────────────┴──────────────────┘
```

| 宽度 | 行为 |
|---|---|
| ≥1280px | 侧栏展开；列表与详情左右分栏 |
| 1024–1279px | 侧栏折叠为 52px 图标栏（悬停显示名称）；列表隐藏来源徽标 |
| <1024px（含 720） | 侧栏隐藏（从命令面板或顶部入口进入模块）；详情改为整页覆盖，左上角有「← 返回」；列表只保留星标、标题、分类、时间 |
| 嵌在 dsh 里 | 隐藏侧栏，模块切换交给 dsh 左栏；其余与对应宽度一致 |

- 整页不得出现横向滚动。筛选条在放不下时，只在筛选条内部横向滚动。
- 长标题在列表中单行省略，悬停用 `title` 显示全文；详情里完整换行，不截断。
- 列表区和详情各自滚动；分组标题在列表内吸顶。

## 6. 页面模式（以灵感台为准，其他模块沿用）

| 页面 | 组成 |
|---|---|
| 清单 | 页头 → 筛选条（全部、收藏、分类，可组合；右侧是计数）→ 可选的提示条 → 列表与详情 |
| 统计 | 页头 → 指标条（4 格）→ 卡片：记录频率热力图 → 卡片：分类分布条。不显示筛选条和详情 |
| 回收站 | 页头 → 分组标题写明保留期 → 行内「恢复」「彻底删除」。不显示详情 |

分段切换（清单 / 统计 / 回收站）放在页头，不单独占一列。

## 7. 组件与状态

所有可交互组件都要覆盖：默认、悬停、键盘焦点（2px 主色描边，1px 间隔）、禁用。适用时还要覆盖选中、加载、错误。

| 组件 | 规则 |
|---|---|
| 按钮 | 主按钮（主色填充，每个区域最多一个）、普通（描边）、幽灵（无边，用于次要操作）、危险（红字；确认框里用红色填充）。高度 28px，卡片内 24px。有快捷键时，在按钮内显示 `kbd` |
| 分段控件 | 槽用 hover 底，选中项用 surface 加轻阴影；`aria-pressed` 或 tab 语义 |
| 筛选胶囊 | 22px 高；选中时用 accent-soft 底、accent 字 |
| 搜索框 | 28px；聚焦时边框变主色；有内容时显示清空按钮；`/` 聚焦 |
| 列表行 | 34px；内嵌圆角，行间无分隔线；顺序固定为星标、标题、摘要、命中字段、分类、来源、时间；悬停用 hover 底；选中用 surface 加 shadow-row；`role="option"` 加 `aria-selected` |
| 分组标题 | 主色、12px、600，后面跟灰色计数；列表内吸顶 |
| 快速记录 | 列表顶部内联展开的白色卡片（类似 Things）：标题（可空）、正文、分类（可不选，自动判断）；⌘↵ 保存，esc 取消；标题和正文都为空时不保存，并给出提示 |
| 详情卡片 | 多标签（最多 6 个，超出关闭最早的）；标签上的「×」悬停时出现；有未保存修改时显示绿点，关闭前确认。内容顺序：工具条 → 标题 → 元信息（分类、来源、时间）→ 正文 → 原文 → 延展 → 追加输入 |
| 原文 | 直接显示，不折叠；与正文相同或已被正文包含（忽略空白差异）时不显示；历史数据（legacy）或为空时不显示 |
| 提示条 | 读取失败和缓存降级用持续可见的条，写明「发生了什么、影响、能做什么」，带重试；`role="alert"` |
| 轻提示（toast） | 底部居中，4 秒自动消失；可逆操作附「撤销」；`role="status"` |
| 确认框 | 只用于不可逆操作；标题写明后果；默认焦点在「取消」；esc 关闭 |
| 命令面板 | ⌘K 开关；上面是命令，下面是灵感搜索结果；↑↓ 选择，↵ 执行，esc 关闭；底部显示操作提示 |
| 空状态 | 区分「还没有内容」（引导创建）、「没有匹配」（提供清除筛选）、「回收站为空」（说明保留期）三种 |

## 8. 键盘

| 键 | 作用 |
|---|---|
| ⌘K | 命令面板 |
| N | 记一条 |
| / | 聚焦搜索 |
| J / K（或 ↓ / ↑） | 在列表中移动并打开详情 |
| ↵ | 打开焦点行 |
| S | 收藏 / 取消收藏 |
| E | 编辑当前详情 |
| ⌘↵ | 保存（快速记录、编辑） |
| ⌫ / Delete | 移入回收站（可撤销） |
| esc | 依次退出：命令面板 / 确认框 → 快速记录 → 编辑 → 搜索框 → 窄屏详情 |

焦点在输入框里时，单字母快捷键不生效。嵌在 dsh 里时，焦点在网页里，dsh 的快捷键大概率不生效；需要的快捷键经消息桥转发（S3 遗留项）。

## 9. 嵌在 dsh 里

- 外观始终是本规范的样式；只有深浅色跟随 dsh：消息桥 `bm:theme` 只取 `dark` 字段，设置根元素的 `data-theme`；
- 隐藏侧栏；页头、列表、详情不变；
- 「在对话中引用」「在右侧栏打开」等对话相关操作，经消息桥请 dsh 执行。不在对话里时，按钮仍在，点了用轻提示说明原因。

## 10. 验收清单（实现页面时）

1. 只用 tokens.css 的变量，不新增散落的颜色和字号。
2. 覆盖这些数据情况：正常、空库、筛选无结果、读取失败（缓存）、长标题、长正文、无原文、原文与正文重复、legacy 原文、多个标签、未保存修改。
3. 检查这些尺寸：1440×900、1280×800、1024×768、720 宽；深色和浅色；独立打开和嵌在 dsh 里。
4. 键盘：第 8 节全部快捷键；焦点顺序合理；焦点始终可见。
5. 浏览器文字放大到 200% 时，不丢失功能与信息。
6. 结论按项写明 verified / failed / not-run。截图在用户首次认可正式页面后，才登记为基线。
