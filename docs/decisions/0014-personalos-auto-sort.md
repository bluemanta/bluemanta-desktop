# ADR 0014：PersonalOS 收件箱每天自动分拣

- 状态：已采纳（2026-11-27 Chris 同意）
- 日期：2026-11-27
- 修订：[ADR 0013](0013-personalos-sources-page.md) 决定 4（后台任务不做上下文自动改写）。这是它唯一的例外。
- 任务与验收记录：[tasks/personalos-auto-sort.md](../tasks/personalos-auto-sort.md)

## 背景

- 收件箱只在晨间简报第 2 步分拣，晨间简报只有 Chris 对 agent 说「早上好」「简报」时才会走。
- 2026-11-22 到 11-27 一次都没走。收件箱里 3 条放了 1 到 5 天，其中两条写的是「明早」，已经过期 4 天，可「今天」页没有把它们标成逾期，因为还没进领域的「未结事项」。
- 接下来要接的微信扫描每天会往收件箱追加事项，靠手动触发分拣跟不上。
- 2026-11-27，Chris 同意做成定时任务，由 Codex 执行。

## 决定

1. **允许一个定时任务每天早上分拣收件箱。** 这是 ADR 0013 决定 4 的唯一例外。其他让 agent 定时改写 PersonalOS 的任务，比如改「现状」、整理近期变化、写知识，仍然不做。
2. **能改的范围。**
   - 读：`收件箱.md`、路由表、各领域的 `状态.md`。
   - 写：各领域（含「我」）`状态.md` 的「未结事项」「近期变化」两节，以及文件顶部的「更新于」；当月日志末尾追加；从 `收件箱.md` 删除已分拣的条目。
   - 不改：「现状」和其他各节、知识、事项文件、资料登记、数据源、协议、蓝图、`README.md`、`AGENTS.md`。不新建领域，不建目录，不删文件。
3. **拿不准就留在收件箱。** 下面几种情况不动那一条：领域可能有两个以上；看不出是待办还是已发生的变化；时间说法换算不出确定日期。相对时间（「明早」「下周一」）按**这条记下的日期**换算，不按分拣那天；换算出来早于今天的照写，它会进「已逾期」。
4. **不重复写。** 目标领域的「未结事项」里已经有同一件事时，不再写一遍，只从收件箱删掉，并在日志里注明「已存在」。
5. **留痕，能撤销。**
   - 每搬一条，在当月日志追加一行 `- YYYY-MM-DD [领域] 分拣：事项文本（收件箱 MM-DD）`。
   - 每次运行最多做一次 Git 提交，说明写 `[分拣] 自动分拣 N 条，留下 M 条`，只暂存这次改过的文件。分错了可以整笔撤回。
   - `收件箱.md` 常有手机追加、还没提交的行，照常一起提交，和晨间存档的例外一样。要写的 `状态.md` 或当月日志在分拣前已经有别人没提交的改动时，照写但不提交，留给晨间存档，并在日志里注明「未提交」。
   - 收件箱是空的时候什么都不改，也不提交。
6. **执行方是 Codex 定时任务。** 每天 07:00，在本机运行，工作目录是 PersonalOS。分拣规则写在 PersonalOS 的 `协议/自动分拣.md`，任务提示词只指向这个文件，规则只有一份。
7. **Git 权限只放开两条。** 在 Codex 规则里长期允许 `git -C /Users/apple/Documents/PersonalOS add` 和 `git -C /Users/apple/Documents/PersonalOS commit` 两个前缀，协议要求提交时一律用这个写法。不给 Codex 整个会话完全访问。上线前手动触发一次，确认提交成功。
8. **登记与提示。** 任务登记进 `我/数据源.md` 的「定时任务」表，「接入」页会显示它有没有按时跑、有没有失败。晨间简报第 2 步改为：自动分拣跑过的话，只处理留下的条目，并在简报里列出今早分拣了哪些、各去了哪个领域。
9. **试运行两周，到 2026-12-11。** 每天的结果记在任务记录里：分了几条、留了几条、分错几条。两周内分错 2 条以上，或者 Chris 觉得不放心，就暂停任务，退回手动分拣。

## 不做

- 微信扫描不直接写领域，仍然先进收件箱，再由本任务分拣。
- 网页不加分拣按钮，也不加分拣预览。
- 不改「现状」，不整理旧的近期变化，不清理已完成的事项。

## 后果

- 好处：
  - 收件箱里的事第二天早上就会进领域，有日期的会出现在「今天」页对应分组里，能打勾。
  - 晨间简报变短，只剩拿不准的条目要问。
- 代价和风险：
  - 每天调用一次模型。
  - Mac 在 07:00 睡眠、或 Codex 应用没开时，任务可能不跑或延后。这一点要在试运行里核实，「接入」页会显示最近一次运行时间。
  - 分错的领域会直接写进正本，靠日志和 Git 发现、撤回。
  - PersonalOS 里有三处写着「不建让 agent 定时改写的任务」：`我/数据源.md` 说明段、蓝图 v0.4、ADR 0013 决定 4。三处都要改成「除自动分拣外」。蓝图 v0.4 输入稿现在有别的会话在改，这一处等那边收尾后再改。
