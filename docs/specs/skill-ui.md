# Skill 台界面规格

- v1：2026-10-22，草案。M1（只读）范围。
- 优先级：**视觉与布局以[设计规范](../design/DESIGN.md)为准**；本文写 Skill 台特有的内容和数据规则。冲突时：设计规范 > 本文 > skill-board 原型。
- 页面模式沿用[灵感台界面规格](idea-ui.md)：同一个网页应用、同一套外壳、组件、快捷键习惯和嵌入方式。本文只写和灵感台不同的地方，没写到的按灵感台做。
- 数据与状态的含义见[交接文档](../skill-desk-handoff.md)第 6 节；网页只经 `/api/v1/skills*` 访问数据。
- 交互参考：用户早先做的原型 `~/Documents/CodeProjects/idash/skill-board`（React + Tailwind，暗色）。**只参考信息结构，不复制代码、样式和数据**，对照见第 8 节。

## 1. 外壳与导航

- **侧栏**：在「灵感台」下面加「Skill 台」（图标用现有 `Icon` 里合适的一个，没有就新增一个线性图标），计数是有问题的 skill 数，没有问题时不显示计数。当前模块用 `aria-current="page"` 标出。
- **页头**（46px）：模块名「Skill 台」、分段控件「清单 / 矩阵 / 问题」、搜索框。M1 没有主按钮。
- **路径**：`/skills`（清单）、`/skills/matrix`、`/skills/issues`、`/skills/item/:name`（清单页并打开这个 skill 的详情；多一层 `item/`，避免名为 `matrix`、`issues` 的 skill 和分段路径冲突）。浏览器前进后退可用。
- **嵌入模式**：`embed=main` 隐藏侧栏，与灵感台相同。M1 不做 `embed=sidebar`。

## 2. 清单（默认页）

### 筛选条（32px）

- 第一组「工具」胶囊：全部、Codex、Claude、Cursor、dsh。选中某个工具时，只显示在这个工具里登记了或检测到的 skill，行上的状态点也只看这个工具。
- 第二组「状态」胶囊：有问题、正常、未启用（`pending`、`disabled`）、外部、未登记。可与工具组合。
- 右侧是计数「N 个」，与当前筛选和搜索一致。

### 搜索

- 占位「搜索名称或描述」；`/` 聚焦；在网页内过滤即可（M1 的数量是几十到一两百个），不另设搜索接口。
- 命中词用 `--bm-mark` 高亮。

### 列表

- 分组，组标题吸顶并带计数，顺序固定：**需要处理**（任一目标为 `broken` / `missing` / `not-link`，或有内容问题）→ **正常** → **未启用** → **外部托管** → **未登记**（只在安装目录里找到的）。组内按名称排序。
- 行 34px，顺序：名称、描述、各工具状态点、`lifecycle` 标签。
  - 名称用 `--bm-font-mono`，因为它就是 `/name` 里要敲的标识符。
  - 描述单行省略，悬停 `title` 显示全文。
  - 状态点：每个工具一个 7px 圆点，后面跟工具缩写（Cx、Cl、Cu、dsh）。颜色不能是唯一信息：圆点带 `aria-label`，如「Codex：软链坏了」。颜色只用 tokens.css 已有的：正常用 `--bm-accent`，有问题用 `--bm-danger`，`pending` 用 `--bm-warn`，其余用 `--bm-text-3`。
  - 1024–1279px 隐藏 `lifecycle` 标签；<1024px 只保留名称和一个汇总状态点。
- 点行或 ↵：在右侧详情打开（第 3 节）。
- 空状态：
  - 找不到 manifest：整区说明「没有找到 skill 登记表」，写出服务端按什么路径找的（`~` 缩写），以及「在启动服务前设置 BLUEMANTA_SKILL_HOME」；
  - 筛选无结果：「没有匹配的 skill」+「清除筛选」。

## 3. 详情

用灵感台的详情卡片（420px，可拖 320–720）。M1 只开一个标签，不做多标签。内容顺序：

1. **工具条**：「复制名称」（复制 `name`）、「复制源目录」（复制完整路径）。不提供打开 Finder、编辑之类的写操作。
2. **标题**：skill 名（等宽）+ manifest 的 `display_name`（如果有）。
3. **元信息**：`visibility`、`lifecycle`、`scope`、源目录（`~` 缩写）。
4. **安装状态**：一张小表，每行一个目标（Codex、Claude、Cursor 以及 manifest 里的其他工具键、dsh 视角），列是「状态」「路径」「说明」。说明写人话，例如「软链指向 ~/Documents/Old/xxx，不是源目录」「manifest 写了待定：Verify Cursor ...（原文照录 `reason`）」「dsh 会加载这个 skill，来自 ~/.agents/skills（rank 500）」「被 ~/.dsh/skills 里的同名 skill 覆盖」。
5. **内容问题**：frontmatter 校验结果。没有问题时不显示这一块。
6. **notes**：manifest 里的 `notes`，按条显示。
7. **SKILL.md**：正文原样显示（等宽、保留换行，详情正文字号）。frontmatter 单独显示成键值表。
8. **目录文件**：源目录下的一级文件和子目录名（不读子目录内容）。

## 4. 矩阵

替代 skill-board 的「表格视图」。页头 → 筛选条（与清单共用）→ 一张表：

- 行是 skill，列是 Codex、Claude、Cursor、manifest 里出现的其他工具键、dsh 视角。
- 格子写状态文字（「正常」「坏了」「没装」「被复制」「待定」「外部」「—」），带对应颜色点。
- 表头吸顶；第一列（名称）横向滚动时固定。整页不得横向滚动，只在表格区域内滚动。
- 点格子或行，跳到清单并打开该 skill 的详情。
- <1024px 不显示矩阵，分段控件里这一项禁用，提示「窗口太窄，请在清单里查看」。

## 5. 问题

与灵感台「回收站」同一种页面模式：页头 → 按问题类型分组的列表，没有详情。

- 分组：软链坏了、该装没装、被复制成普通目录、源目录或 SKILL.md 缺失、frontmatter 不合 dsh 规则、名称与目录名不一致、未登记、dsh 同名覆盖。每组标题后是计数。
- 每行：skill 名、目标、一句说明、**建议的处理方式**。能用现有命令处理的，显示命令和「复制命令」按钮，例如 `python3 ~/Documents/AgentSkillRepos/skill-manager/scripts/skill_manager.py install --name <name>`。M1 只复制，不执行。
- 没有问题时显示「全部正常」，并写明检查时间。

## 6. 键盘

| 键 | 作用 |
|---|---|
| `/` | 聚焦搜索 |
| J / K（或 ↓ / ↑） | 在清单中移动并打开详情 |
| ↵ | 打开焦点行 |
| esc | 依次退出：命令面板 → 搜索框 → 窄屏详情 |
| P / ⌘K | 命令面板（规则同灵感台：嵌入时 ⌘K 归 dsh） |

灵感台的 `N`、`S`、`E`、`⌫` 在 Skill 台**不生效**。命令面板加命令「打开 Skill 台」「切换到矩阵」「打开问题」；M1 不在命令面板里搜索 skill。

## 7. 数据刷新、错误与状态

- 窗口重新获得焦点时重新读取；另有「重新检查」按钮放在问题页页头。不做文件监视。
- 读取失败、口令失效：与灵感台第 11 节相同（提示条、缓存、整页「需要重新打开」）。
- manifest 解析失败：提示条写明行号和原因（来自接口），已解析出的部分不显示，避免半份数据被当成全部。
- 读取 skill 目录时某一项读不了（权限、断链）：这一项记为对应状态，不让整页失败。

## 8. 从 skill-board 原型取什么

| skill-board | Skill 台 | 原因 |
|---|---|---|
| 左侧「来源 Agent」栏 | 筛选条第一组胶囊 | 侧栏只放模块导航（设计规范第 5 节） |
| 总览四卡 | 不做；有问题的数量放在侧栏计数和问题页 | 「本周活跃」「最近使用」没有真实数据 |
| 最近使用列表、活跃 / 闲置 | 不做（M1） | 原型里是演示事件，不能伪装成真实数据（设计规范原则 6） |
| 卡片网格 | 34px 列表 | 工具感、高密度（设计规范原则 1） |
| 表格视图 | 矩阵页 | 按工具看安装状态是这个模块的核心 |
| 右侧抽屉 | 详情卡片 | 设计规范第 7 节，不用蒙版和抽屉 |
| 常用（钉选）、归档 | 不做（M1）；归档对应 manifest 的 `lifecycle` 和已停用目录 | 不另设一份「归档」状态；常用要存偏好，留到 M2 |
| 添加 / 编辑弹窗、localStorage | 不做 | 会变成 skill 的第二份正本（硬规则 1）；写操作在 M2 经预览确认 |
| 暗色、紫色主按钮、Tailwind | tokens.css，深浅色跟随 dsh，主色绿 | 设计规范第 1、3 节 |
| 技能名等宽、Asia/Shanghai 时间、不显示调用次数 | 保留 | 与规范一致 |
| 「示例数据」横幅 | 不需要 | 数据是实时读取的真实状态 |
