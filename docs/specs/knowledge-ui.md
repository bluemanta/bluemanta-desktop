# 知识台界面规格

- v1：2026-10-26。第一版只读范围（[ADR 0009](../decisions/0009-knowledge-desk.md)）。
- 优先级：**视觉与布局以[设计规范](../design/DESIGN.md)为准**；本文写知识台特有的内容和数据规则。冲突时：设计规范 > 本文。
- 页面模式沿用[灵感台界面规格](idea-ui.md)：同一个网页应用、同一套外壳、组件、快捷键习惯和嵌入方式。本文只写和灵感台不同的地方，没写到的按灵感台做。
- 网页只经 `/api/v1/knowledge*` 访问数据。

## 1. 外壳与导航

- **侧栏**：加「知识台」（线性图标，书本样式）。计数是个人库 `_Inbox` 里的文件数，为 0 时不显示。
- **页头**（46px）：模块名「知识台」、分段控件「主题 / 搜索 / 收件箱」、搜索框（占位「搜索知识和灵感」，`/` 聚焦，回车进入搜索页）。第一版没有主按钮。
- **路径**：
  - `/knowledge`：主题页，默认个人库；
  - `/knowledge/lib/:lib`：主题页，指定库；
  - `/knowledge/lib/:lib/topic/*`：主题页并在右侧打开该主题（`*` 是主题在库内的相对路径）；
  - `/knowledge/lib/:lib/file/*`：在右侧打开库内任一文件（阅读器）；
  - `/knowledge/search?q=`：搜索页；
  - `/knowledge/inbox`：收件箱。
- **嵌入模式**：`embed=main` 隐藏侧栏；`embed=sidebar` 只显示右侧阅读器（dsh 右侧栏打开一个文件或主题时用）。

## 2. 主题页（默认）

### 筛选条（32px）

- 库胶囊：「个人」「Arsenal」，后面跟「只读」小标（第一版两个都是只读，Arsenal 始终只读）。库目录不存在时胶囊置灰，悬停说明找的路径（`~` 缩写）。
- 状态胶囊：全部、活跃（`active`）、种子（`seed`）、待审（`needs_review`）、未登记（磁盘上有、总索引里没有）。
- 右侧计数「N 个主题」。

### 列表

- 按分类分组，组标题是分类名（去掉编号前缀，如「职业与业务」），吸顶并带计数，顺序按编号。
- 行 34px：主题名、别名（灰色，单行省略）、状态标签、最后审阅日期（无则空）。悬停 `title` 显示总索引里的 Notes。
- 点行或 ↵：右侧打开主题详情（第 3 节）。J / K 移动。
- 空状态：
  - 库目录不存在：整区说明「没有找到这个库」，写出路径与「在启动服务前设置 BLUEMANTA_KNOWLEDGE_HOME」；
  - 没有总索引：仍按目录列出主题，顶部提示「这个库没有总索引，主题都标为未登记」。

## 3. 主题详情（右侧卡片）

用灵感台的详情卡片（420px，可拖 320–720），第一版只开一个标签。

1. **标题**：主题名 + 库名小标；元信息行：分类、状态、最后审阅、主题路径（`~` 缩写，可点「复制路径」）。
2. **页签**：「概览」（README.md）、「资产」（Asset_Index.md）、「知识」（Topic_Knowledge.md）、「日志」（Topic_Log.md）、「文件」。缺哪个文件，对应页签显示「这个主题还没有 X」，不隐藏页签，保持位置稳定。
3. **文件页签**：主题根目录的其他文件（不含 `_Archive`），每行：文件名、类型、大小、修改日期。Markdown 点开进阅读器；其他文件只显示元信息和「复制路径」。`_Archive` 收成一行「归档 N 个」，展开后同样列出。
4. 路由信息（别名、关键词、典型问题、相关主题）来自总索引，显示在概览页签顶部；相关主题可点击跳转。

## 4. 阅读器

- Markdown 渲染：标题、列表、表格、代码、引用、链接。不渲染原始 HTML。表格横向可滚动，单元格不换行省略、悬停看全文（总索引和资产索引的表都很宽）。
- 库内相对链接（`.md`）在阅读器内打开；指向库内其他文件的链接显示文件元信息；外部链接新窗口打开。
- 顶部：面包屑「库 / 分类 / 主题 / 文件名」，「复制路径」。长文显示右侧目录（≥1280px 时，按二、三级标题）。
- 正文字号与灵感详情一致。

## 5. 搜索页

- 输入框沿用页头搜索；结果分组：**个人库**、**Arsenal**、**灵感**，组标题带计数；某组无结果时不显示该组。
- 结果行（两行高）：第一行是文件名或灵感标题 + 标题链（如「会员体系 › 常见客户问题」）；第二行是摘录，命中词用 `--bm-mark` 高亮。归档里的结果加「归档」小标、排在组末。
- 点结果：知识文件在右侧阅读器打开并滚动到命中段；灵感跳到灵感台对应详情。
- 库胶囊可筛选来源（个人、Arsenal、灵感）。
- 空状态：「没有找到」+ 提示「换个说法，或只用一两个关键词」。

## 6. 收件箱

- 列出个人库 `_Inbox/` 里的文件（不含 `README.md`）：文件名、修改日期、大小。点开进阅读器。
- 第一版只读，顶部一行说明「新材料先放进这里，入库功能在下一版」。

## 7. 键盘

沿用设计规范第 8 节；本模块的单字母键：`/` 聚焦搜索、J / K 移动、↵ 打开、esc 关闭右侧卡片。命令面板（P）里加「切换到 知识台」「搜索知识」。

## 8. 走查与截图

Playwright 走查用虚构库（fixture），覆盖：两个库切换、库不存在、无总索引、主题四页签与缺文件、文件页签与归档、阅读器表格与相对链接、搜索三组结果与高亮、收件箱、嵌入 `main` 与 `sidebar`。截图尺寸与灵感台一致（1440、1280、1024、720 × 深浅色）。
